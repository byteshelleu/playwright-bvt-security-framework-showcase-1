# tools

| Tool | Purpose |
|---|---|
| `rules_checker.py` and `rules/` | The rule checker: architecture and coding rules ruff and mypy do not cover, by rule id |

| `juice_shop.py` | Confirms Juice Shop answers on this machine |
| `case_areas.py` | The CI areas holding the selected cases |
| `case_report.py` | Merges every area's JUnit into one case report through the adapter |
